# mini-bank-transfer
A simple banking transfer simulator built with Python.
## 학습 기록 - Python 딕셔너리와 반복문

### 1. 오늘 학습한 개념

- **Dictionary:** Key와 Value를 이용해 여러 계좌의 잔액을 관리하는 자료구조
- **while True:** 사용자가 종료를 선택할 때까지 메뉴를 반복 실행
- **input():** 사용자에게 입력받은 문자열을 반환
- **print():** 값을 화면에 출력하지만 반환값은 None
- **if / elif / else:** 여러 조건을 순서대로 검사하고 하나의 분기 실행
- **in 연산자:** 딕셔너리에 특정 Key가 존재하는지 확인

### 2. 구현한 기능

- A, B, C 계좌의 잔액을 딕셔너리로 관리
- 사용자에게 계좌 조회 메뉴 제공
- 존재하지 않는 계좌에 대한 안내 메시지 출력
- 사용자가 0을 입력하면 프로그램 종료

### 3. 발생한 문제와 해결 과정

**문제 1: 입력한 계좌가 정상적으로 조회되지 않음**

처음에는 `x = print(input("조회할 계좌: "))`라고 작성했다.

하지만 `print()`는 입력값을 반환하지 않고 `None`을 반환하기 때문에 `x`에 계좌 이름이 저장되지 않았다.

이를 `x = input("조회할 계좌: ")`로 수정했다.

**문제 2: 존재하는 계좌인데도 오류 메시지가 출력됨**

여러 개의 독립적인 `if`문을 사용했기 때문에 마지막 `if`에 연결된 `else`가 의도치 않게 실행될 수 있었다.

이를 `if-elif-else` 구조로 수정해 조건을 하나의 흐름으로 처리했다.

### 4. 느낀 점

코드에 문법 오류가 없어도 의도한 결과와 다르게 실행될 수 있다는 점을 배웠다. 특히 함수의 출력값과 반환값이 다르다는 것을 이해했고, 조건문의 구조가 프로그램 실행 결과에 영향을 준다는 것을 알게 되었다.
